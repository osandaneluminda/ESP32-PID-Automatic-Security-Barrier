# ESP32 PID Automatic Security Barrier System

## Project Overview
An automatic security barrier system developed using ESP32, ultrasonic distance sensing, and PID-based servo control with AS5600 magnetic encoder feedback.

## Features
- Automatic vehicle detection using HC-SR04 ultrasonic sensor.
- Barrier movement controlled by an SG90 servo motor.
- AS5600 magnetic encoder for angle feedback.
- PID control system design.
- RGB LED warning indication.
- MATLAB/Simulink modelling and simulation.
- GUI-based system monitoring.

## Technologies & Components
- ESP32
- HC-SR04 Ultrasonic Sensor
- SG90 Servo Motor
- AS5600 Magnetic Encoder
- MATLAB/Simulink
- C/C++
